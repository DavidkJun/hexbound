# BUG-012: small text (13 px) below 4.5:1 contrast on map tiles and danger states

| **Owner** | UI / Level designer |

| **Status** | Open |

`text.small` is 13 px, so WCAG 2.1 AA asks for 4.5:1.

| Where | Text colour on background | Contrast |
|---|---|---|
| Detail label ("Bog rat", "Food") on Frostpeak ground | `text.primary` on #C9D6DF | **1.27:1**. The spec doesn't say which colour labels use on light ground (S-20). |
| Marker "burn" on lava | `text.primary` on #E0602F | 3.06:1 |
| Detail label on Whisperwood ground | `text.primary` on #6B8A4E | 3.35:1 |
| "Not enough food", unaffordable price | `accent.danger` on `bg.raised` | 3.47:1 |

**Expected:** ≥ 4.5:1 for 13–16 px text.

**Suggested fix:**

- Labels and markers on tiles: use `text.inverse` on light lands, or put the label on a small dark pill (`bg.base` at 80%).
- Danger text: a lighter red for text (e.g. #F07A7A is 4.82:1 on `bg.raised`), keeping #E05555 for fills.
