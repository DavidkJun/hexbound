**Steps**

1. In `data/enemies/_example.json`, give `bog-rat` two moves with `"id": "bite"` (different names or effects), and `pattern: { "type": "cycle", "order": ["bite"] }`.
2. Run `npm run check:data`.

**Expected:** `[0].moves[1].id: "bite" is already used`. Pattern `order`, `weights` and `signature.move` refer to moves by id, so ids must be unique.

**Actual:** `examples: ok`. Which "bite" is played is undefined.

**Suggested fix:** in `superRefine`, report an issue when `moveIds.size !== enemy.moves.length`.
