# BUG-010: the design document PDF can't be searched or copied

| | |
|---|---|
| **Build and seed** | `plan/HexBound_DD.pdf` at commit 41ce590 |
| **Severity** | Minor |
| **Owner** | PM / Game designer |
| **Found by** | design review (task 1) |
| **Status** | Open |

**Steps**

1. Open `plan/HexBound_DD.pdf`.
2. Search for "Freeze", or copy a paragraph into a text editor (or run `pdftotext`).

**Expected:** the text is searchable and copies as text. Testers copy rules into test cases, and teammates search for numbers.

**Actual:** the fonts are embedded without a Unicode map. Copied text comes out as substituted letters ("WTB LKYB" for "The game"), and some digits (5, 6, 8) are drawn as unmapped shapes. For example, the number of choice events in the must-have list can't be read as text (see G-32).

**Suggested fix:** re-export the PDF with standard fonts (Google Docs / Word → "Download as PDF" usually works), or add the source document (`.md` or `.docx`) next to the PDF.
