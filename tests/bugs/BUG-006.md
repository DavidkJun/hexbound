**Steps**

1. `design/screens.md` › TopBar: "Chips have padding 6/12 (10 on the left)".
2. `design/screens/map.md` › TileTooltip: "padding 10/12".
3. `design/tokens.json` › `space`: 4, 8, 12, 16, 24, 32.

**Expected:** every size the code needs is a token. ui-rules §2: "Never type a … pixel size … If a value you need is missing, ask … to add a variable".

**Actual:** 6 and 10 are not in `tokens.space`, so code must hard-code them, which is the rule the ESLint setup is meant to prevent.

**Suggested fix:** add `space.chip-y = 6` and `space.tooltip-x = 10` (or snap them to 4 and 8 / 12) in Figma variables, then re-export.
