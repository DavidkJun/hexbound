# BUG-007: on Node older than 22.12, install "succeeds" but test, build and dev crash with a misleading error

| | |
|---|---|
| **Build and seed** | build b9977c9 (PR #2) · Node 22.4.1, npm 10.8.1, Linux x64 (WSL2) |
| **Severity** | Major. It blocks a teammate from running the project locally, which is part of the stage 0 "done when" ("the other three can run it locally"). |
| **Owner** | Programmer (`package.json` engines, README "Run it") |
| **Found by** | manual test TC-S0-03, while setting up the tester's machine |
| **Evidence** | [`../results/stage-0/04-node-22.4-repro.log`](../results/stage-0/04-node-22.4-repro.log) (clean copy, full output) |
| **Status** | Open |
| **Issue** | [#9](https://github.com/DavidkJun/hexbound/issues/9) |

**Steps**

1. Use Node 22.4 (Ubuntu's default `nodejs` package is older still).
2. Clone the repository; run `npm ci` and then `npm test` (or `npm run dev` or `npm run build`).

**Expected:** either it works, or `npm ci` stops with a clear "Node 22.12 or newer is required".

**Actual:**

- `npm ci` only prints `npm warn EBADENGINE` (easy to miss) and exits 0. npm then skips the rolldown native binding, whose engines need ≥ 22.12.
- `npm test`, `npm run build` and `npm run dev` crash with `Error: Cannot find native binding. npm has a bug related to optional dependencies…`. The message points at an npm bug, not at the Node version.
- With Node 24 (`.nvmrc`) everything works: [`01-programmer-check.log`](../results/stage-0/01-programmer-check.log).

**Suggested fix:**

1. Add `.npmrc` with `engine-strict=true`, so `npm ci` fails with a clear message.
2. In the README "Run it" section, say "Node 24 (see `.nvmrc`): `nvm use`".
3. Optionally, align `engines.node` with `.nvmrc`. The README says 22.12+, but CI uses 24.
