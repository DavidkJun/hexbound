**Steps**

1. In a level file, set `"start": [0, 7]` (row 7 doesn't exist; rows are 0–6).
2. Open the game, or run `npm run check:data`.

**Expected:** ui-rules §9 asks for a "clear message (file, field, coordinate)", e.g. `data/levels/whisperwood.json › start: tile 0,7 is outside the grid (col 0–8, row 0–6)`.

**Actual:** `data/levels/whisperwood.json › start[1]: Too big: expected number to be <=6`. It names neither the bad value (7) nor the tile, and "start[1]" means "row" only to someone who knows the format.

**Suggested fix:** a custom message in `coordinateSchema`, e.g. `` `${value} is outside the grid: ${axis} goes from 0 to ${size - 1}` ``.
