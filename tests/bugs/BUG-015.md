# BUG-015: an `allow` list that repeats a type is accepted

| | |
|---|---|
| **Build and seed** | main 73f39a3 · seed: not needed (data check) |
| **Severity** | Minor |
| **Owner** | Programmer (`src/data/schema.ts`, `levelSchema.slots`) |
| **Found by** | `tests/auto/map-format.test.ts` › `BUG-015 TC-MAP-07f` (`it.fails`; the control test `TC-MAP-07f-control` passes) |
| **Status** | Open |

The rule changed in main abced2c, the designer's answer to note N-07. `design/levels/map-format.md` rule 7 now says: "`allow` lists … list each type at most once: `["monster", "monster", "chest"]` is an error."

**Steps**

1. In `data/levels/_example.json`, set one slot to `{ "at": [2, 5], "allow": ["monster", "monster", "chest"] }`.
2. Run `npm run check:data`.

**Expected:** `data/levels/_example.json › slots[0].allow: "monster" is listed twice`.

**Actual:** `examples: ok`. The deal then picks `monster` twice as often as `chest`, which the format says must never happen.

**Suggested fix:** `.refine((types) => new Set(types).size === types.length, …)` on the `allow` array.
