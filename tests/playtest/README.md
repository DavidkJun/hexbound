# Playtests

- [`checklist.md`](checklist.md): questions per design pillar and the measurable targets from the design document.
- [`playtest-log.csv`](playtest-log.csv): the table to fill during playtests, one row per level played. The first row is an example to delete. It opens in Google Sheets or Excel.

**Columns:**

- `routes_looked_at`: routes planned before the first Go.
- `fight_turns`: turns of each normal fight on that level, separated by `;`.
- `p1_…` to `p4_…`: short answers to the checklist questions.

Health is `current/max`. Times are in minutes.
